PRESENTACIÓN

UNA FUENTE CONECTADA NO ES ACCESO ILIMITADO

Un conector —denominado actualmente app en la experiencia de ChatGPT— es una integración autorizada entre ChatGPT y un servicio externo. Permite buscar, referenciar o utilizar información dentro del alcance concedido. Algunas apps también admiten acciones, pero deben solicitar confirmación antes de producir efectos externos.

Puede hacer

  • Buscar correos, archivos, eventos, contactos o páginas autorizadas.
  • Referenciar fuentes y apoyar investigación.
  • Ejecutar acciones cuando la app y el espacio lo permiten.

No puede asumir

  • Acceso universal a toda la cuenta.
  • Disponibilidad idéntica por plan o región.
  • Permiso automático para crear, enviar, editar o eliminar.

Disponibilidad

Depende de producto, plan, región, cuenta, administrador, app, capacidades y configuración.

CONCEPTOS

CONECTAR, CONSULTAR, SINCRONIZAR Y ACTUAR

ConceptoFunciónLímite esencial
Conector / appIntegra ChatGPT con una fuente o herramienta autorizada.Solo opera con permisos y capacidades disponibles.
Archivo adjuntoSe entrega directamente en una conversación.No consulta por sí mismo una fuente vinculada.
WorkCoordina investigación, archivos, tareas y entregables.Puede usar apps disponibles, pero no las sustituye.
Computer UseInteractúa visualmente con interfaces.Una integración estructurada puede ser preferible.
APIOfrece control técnico mediante desarrollo y autenticación.Requiere programación y gobierno propio.
AutomatizaciónEjecuta tareas futuras, recurrentes o condicionadas.Acceso a una fuente no equivale a programación.
SyncIndexa contenido anticipadamente cuando la app lo soporta.Conectar no significa copiar permanentemente toda la cuenta.
Permisos: el usuario o administrador autoriza el alcance. Debe poder revisar la cuenta, limitar acciones y desconectar o revocar el acceso según las opciones vigentes.

PUNTO DE PARTIDA

PARA QUIÉN ES Y QUÉ APRENDERÁ

Público objetivo

Profesionales, administradores, operaciones, docentes, investigadores, analistas, responsables de procesos, usuarios de Work y equipos que gestionan información externa.

Requisitos

Cuenta y servicio compatibles, permisos suficientes, conocimiento básico, datos autorizados, política institucional, capacidad de revocar acceso y entorno de prueba cuando corresponda.

Objetivos

Explicar conectores; diferenciarlos de archivos, Work, Computer Use, API y automatización; autorizar con mínimo acceso; consultar, validar, confirmar acciones, revocar y registrar evidencias.

FLUJO SUPERVISADO

CÓMO CONECTAR Y CONSULTAR UNA FUENTE AUTORIZADA

  1. Definir el objetivo.
  2. Identificar la fuente adecuada.
  3. Revisar disponibilidad.
  4. Seleccionar la cuenta correcta.
  5. Examinar permisos solicitados.
  6. Autorizar únicamente lo necesario.
  7. Realizar una consulta de prueba.
  8. Verificar fuente y resultado.
  9. Evitar datos sensibles innecesarios.
  10. Confirmar cualquier escritura.
  11. Registrar consulta, resultado e incidencia.
  12. Revocar o mantener el acceso según necesidad.

Ejercicio

Consulta controlada de información desde una fuente conectada. Localice información no sensible en una cuenta autorizada y produzca objetivo, fuente, cuenta, permisos, consulta, resultados, evidencias, incidencias, validación y decisión de acceso.

Caso demostrativo ZYRON — escenario educativo ficticio

Necesidad → selección de fuentes → permisos → calendario → documentos → resumen → validación humana → evidencias. No representa clientes, cuentas ni resultados reales.

Entregable

Plan de consulta, inventario de fuentes, matriz de permisos, registro, evidencias, resultados, validación, incidencias, decisión de acceso y rúbrica.

SEGURIDAD Y PRIVACIDAD

RIESGOS QUE DEBEN CONTROLARSE

  • Cuenta equivocada, permisos excesivos o acceso a información innecesaria.
  • Datos desactualizados, resultados incompletos o fuente incorrecta.
  • Cambios no autorizados, envío o eliminación accidental.
  • Exposición privada, retención, trazabilidad y dependencia externa.
  • Disponibilidad variable, restricciones regionales y desconexión incompleta.
  • Diferencias entre lectura y escritura y necesidad de supervisión humana.
PREGUNTAS FRECUENTES

DIECIOCHO RESPUESTAS ESENCIALES

1. ¿Qué es un conector?

Una integración autorizada, hoy presentada como app, entre ChatGPT y un servicio.

2. ¿Puede ver toda mi cuenta?

No debe asumirse; el alcance depende de permisos, servicio y configuración.

3. ¿Qué diferencia hay con subir un archivo?

El archivo se entrega al chat; la app consulta una fuente vinculada.

4. ¿Qué diferencia hay con Work?

Work coordina tareas y entregables; las apps aportan fuentes autorizadas.

5. ¿Qué diferencia hay con Computer Use?

La app usa acceso estructurado; Computer Use interpreta una interfaz.

6. ¿Qué diferencia hay con una API?

La API requiere desarrollo y ofrece control técnico propio.

7. ¿Qué diferencia hay con automatización?

Conectar habilita acceso; automatizar programa o condiciona tareas.

8. ¿Todos están disponibles en Plus?

No. Plan, región, app y capacidad pueden variar.

9. ¿Puedo elegir la cuenta?

El flujo de autorización debe permitir verificar la cuenta correcta.

10. ¿Qué permisos concedo?

Solo los mínimos necesarios para el objetivo.

11. ¿Puedo revocar acceso?

Sí, mediante los controles vigentes de ChatGPT, la app o el servicio.

12. ¿Puede enviar correos?

Solo si la app, plan y configuración admiten escritura, con confirmación.

13. ¿Puede crear eventos?

Depende de la capacidad disponible y requiere confirmación externa.

14. ¿Puede modificar archivos?

Solo cuando existe una acción autorizada y configurada.

15. ¿Qué datos no conecto?

Secretos o datos sensibles innecesarios, prohibidos o sin autorización.

16. ¿Cómo verifico lo consultado?

Abra la fuente original y contraste contexto, fecha, propietario y contenido.

17. ¿Cómo desconecto una fuente?

Use los controles de la app y confirme la revocación en el servicio.

18. ¿Qué ocurre si cambia la disponibilidad?

Revise el directorio, notas oficiales, plan, región y configuración actual.
