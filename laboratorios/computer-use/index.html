COMPUTER USE

DEFINICIÓN

OBSERVAR, RAZONAR, ACTUAR Y COMPROBAR

Computer Use es la capacidad de un agente para interpretar una interfaz gráfica autorizada —pantallas, botones, menús, campos y estados— y producir acciones como hacer clic, escribir, desplazarse y completar tareas de varias etapas.

Puede hacer

  • Interpretar elementos visibles.
  • Navegar por pasos.
  • Introducir datos autorizados.
  • Solicitar confirmación.
  • Registrar y validar acciones.

No debe hacer

  • Controlar ilimitadamente un equipo.
  • Operar sin permisos.
  • Evadir seguridad o CAPTCHA.
  • Ejecutar acciones sensibles sin revisión.
  • Sustituir API, conectores o controles humanos cuando sean la vía adecuada.

Herramientas posibles

  • Navegador remoto o integrado.
  • Aplicaciones autorizadas.
  • Capturas y reconocimiento visual.
  • Cursor, teclado y desplazamiento.
  • Registros, confirmaciones y toma de control.
DISTINCIONES

TECNOLOGÍA, PRODUCTO Y SUPERFICIE NO SON LO MISMO

ConceptoQué significaEstado o límite
CUAComputer-Using Agent: arquitectura que interpreta interfaces y genera acciones.No es una aplicación universal independiente.
OperatorExperiencia anterior de OpenAI para actuar en sitios web mediante un navegador propio.Su funcionalidad se integró en experiencias agénticas posteriores; el sitio independiente dejó de estar disponible.
ChatGPT agent modeExperiencia histórica que integró las capacidades web de Operator y permitía desplazarse, hacer clic y escribir.La documentación oficial vigente indica que ChatGPT agent ya no está disponible y remite a Work y Cloud browser.
Cloud browserNavegador remoto desde Work para tareas compatibles en sitios públicos.En su disponibilidad inicial no acepta credenciales, inicio de sesión ni pagos; se detiene ante pasos incompatibles.
Codex Computer UseInteracción con aplicaciones e interfaces durante desarrollo, pruebas y depuración cuando esté habilitada.Depende de plataforma, cuenta, versión, región, permisos y configuración.
Importante: Computer Use no equivale a controlar libremente todo el equipo. El alcance real lo determina la superficie utilizada y los permisos concedidos.

PARA QUIÉN ES Y QUÉ APRENDERÁ

Profesionales, administradores, desarrolladores, analistas, operaciones, diseñadores de procesos, docentes, investigadores y usuarios de agentes.

Cuenta y plataforma compatibles, aplicación actualizada, conexión estable, tarea definida, datos autorizados, seguridad básica y capacidad de detener o tomar el control.

FLUJO SUPERVISADO

CÓMO PREPARAR Y SUPERVISAR UNA TAREA

  1. Definir el objetivo.
  2. Identificar aplicaciones y páginas autorizadas.
  3. Clasificar los datos.
  4. Establecer acciones permitidas y prohibidas.
  5. Definir puntos de confirmación.
  6. Preparar el entorno.
  7. Iniciar la tarea.
  8. Observar la interpretación de la interfaz.
  9. Confirmar o rechazar acciones sensibles.
  10. Tomar el control ante dudas.
  11. Verificar el resultado.
  12. Registrar acciones, incidencias y aprobación.

Ejercicio práctico

Supervisión de una tarea demostrativa: navegar, localizar información y completar campos no sensibles sin compras, pagos, publicaciones ni envíos reales.

Caso demostrativo ZYRON — escenario educativo ficticio

Revisión supervisada de un formulario institucional: necesidad → alcance → permisos → interfaz → confirmaciones → validación → evidencias → resultado aprobado.

Entregable

Plan, matriz de permisos, registro de acciones, confirmaciones, evidencias, incidencias, resultado, lista de verificación, rúbrica y aprobación humana.

RIESGOS Y LIMITACIONES

LA INTERFAZ PUEDE CAMBIAR, ENGAÑAR O SER MAL INTERPRETADA

  • Interpretación visual o clic incorrecto.
  • Campos, cuentas o destinatarios equivocados.
  • Interfaces modificadas y estados ambiguos.
  • Prompt injection, phishing y sitios fraudulentos.
  • Permisos excesivos o exposición de credenciales.
  • Publicaciones, envíos, compras, pagos o eliminaciones accidentales.
  • CAPTCHA, autenticación y bloqueos que requieren detenerse.
  • Disponibilidad variable y falta de trazabilidad.
  • Necesidad permanente de supervisión humana.
No escriba contraseñas ni códigos en el chat. Use la toma de control cuando una superficie autorizada requiera credenciales y revise la cuenta activa antes de continuar.
PREGUNTAS FRECUENTES

DIECISÉIS RESPUESTAS ESENCIALES

1. ¿Controla todo mi equipo?

No. Solo actúa dentro de superficies y permisos disponibles.

2. ¿Qué diferencia hay con agent mode?

Agent mode fue una experiencia histórica de ChatGPT; Computer Use es una capacidad más amplia.

3. ¿Operator sigue existiendo?

No como sitio independiente vigente; sus capacidades se integraron posteriormente.

4. ¿Qué es CUA?

La arquitectura que interpreta interfaces y produce acciones.

5. ¿Puede introducir contraseñas?

El usuario debe tomar el control; no debe escribirlas en el chat.

6. ¿Puede realizar compras?

No debe completar compras o pagos sin una superficie compatible y confirmación humana; Cloud browser no los admite inicialmente.

7. ¿Cuándo confirma?

Antes de acciones con efectos externos, sensibles o difíciles de revertir.

8. ¿Puedo tomar el control?

Sí, y debe hacerlo ante credenciales, ambigüedad o riesgo.

9. ¿Puede interpretar mal la pantalla?

Sí. La interfaz y el resultado deben verificarse.

10. ¿Puede usar aplicaciones Windows?

Codex Computer Use puede hacerlo para cuentas y entornos elegibles.

11. ¿Qué diferencia hay con Codex?

Codex es la experiencia técnica; Computer Use puede ser una de sus herramientas.

12. ¿Qué diferencia hay con Work?

Work coordina tareas y entregables; puede usar navegador cuando corresponde.

13. ¿Por qué no usar siempre una API?

La API es preferible cuando ofrece acceso estructurado y auditable.

14. ¿Puede superar CAPTCHA?

No debe evadirlo; debe detenerse o devolver el control.

15. ¿Qué no debo mostrar?

Credenciales, secretos y datos innecesarios o no autorizados.

16. ¿Cómo registro lo realizado?

Con pasos, confirmaciones, incidencias, evidencias mínimas y aprobación final.

CIERRE INSTITUCIONAL

LA AUTONOMÍA OPERATIVA EXIGE SUPERVISIÓN

ZYRON estudia Computer Use como una capacidad para asistir tareas autorizadas, no para eliminar permisos, controles ni responsabilidad humana. Una tarea solo está completa cuando su resultado fue verificado y aprobado.
