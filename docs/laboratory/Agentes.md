# Agentes - ZYRON AI LAB

## Proposito

Documentar el estudio y aplicacion de agentes inteligentes dentro del ecosistema ZYRON.

## Lineas de trabajo

- Agentes de desarrollo web.
- Agentes de productividad.
- Agentes de automatizacion.
- Multiagentes.
- Conectores.
- Computer Use.

## Estado

La estructura base existe dentro del Centro de Investigacion OpenAI. El Laboratorio Codex documenta desde 2026-07-15 el flujo supervisado de agentes de programación: inspección, delimitación, planificación, implementación, verificación y entrega. El contenido específico de los demás agentes continúa pendiente.

## Relación con Laboratorio Codex

- Codex se presenta como agente de programación, no como sustituto de la revisión humana.
- Las instrucciones del repositorio, el alcance y la definición de finalización preceden a la implementación.
- Sandbox y aprobaciones se documentan como controles distintos.
- Pruebas, revisión y evidencia forman parte del flujo de trabajo.
