# DEC-001 - Documentacion obligatoria por sesion

## Fecha

2026-07-11

## Decision

Toda sesion de desarrollo del proyecto ZYRON debe finalizar con actualizacion documental.

## Motivo

Evitar perdida de contexto, conservar trazabilidad y permitir continuidad inmediata entre sesiones.

## Consecuencia

Los siete archivos principales de `docs/` deben revisarse y actualizarse antes de cerrar cualquier trabajo.

## Estado

Aprobada.
