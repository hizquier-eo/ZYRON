# Memoria definitiva — Fase 1F Laboratorio Conectores

La Fase 1F desarrolló el Laboratorio Conectores como programa educativo sobre acceso autorizado a fuentes externas en ChatGPT. Se documentó la terminología vigente de apps/conectores, búsqueda, sync, acciones, permisos, confirmaciones, privacidad, revocación y disponibilidad variable.

## Resultado

Se completaron ocho módulos, tutorial, ejercicio, caso demostrativo ZYRON, entregable, rúbrica, seguridad, dieciocho preguntas frecuentes y siete fuentes oficiales. Se publicaron cinco recursos en diez archivos: dos DOCX, tres XLSX y cinco PDF.

La página fue validada en 1440×900, 768×1024 y 390×844. Se corrigió el desbordamiento móvil mediante estilos exclusivos de `.connectors-lab-page`. Las diez descargas respondieron HTTP 200 con MIME y tamaño válidos. Se inspeccionaron los PDF y todas las hojas XLSX; las fórmulas de la rúbrica no presentan errores.

Se sincronizó el estado **Activo** en la página, Centro OpenAI y Mapa ZYRON.

Versión aprobada: **0.17.0**.
