# Laboratorio Codex - Ficha inicial

## Qué es

El Laboratorio Codex es el módulo de ZYRON AI LAB dedicado al desarrollo asistido por agentes de programación. Codex puede escribir, comprender, revisar y depurar código; el laboratorio organiza esas capacidades dentro de un proceso supervisado y verificable.

## Para qué sirve

- Comprender la estructura y las instrucciones de un repositorio.
- Diagnosticar errores con evidencia antes de modificar archivos.
- Planificar e implementar cambios con alcance controlado.
- Refactorizar y documentar código sin alterar funciones ajenas.
- Ejecutar pruebas y revisar el resultado antes de entregarlo.
- Preparar publicaciones sin ejecutarlas hasta obtener autorización.

## Qué aprenderás

- Cómo aportar a Codex el propósito, alcance, archivos relevantes, restricciones y criterio de finalización de una tarea.
- Cómo usar instrucciones persistentes del repositorio, como `AGENTS.md`, cuando existan.
- Cómo distinguir entre sandbox, aprobaciones y acciones externas.
- Cómo conservar cambios existentes y evitar operaciones destructivas.
- Cómo seleccionar verificaciones proporcionales al riesgo.
- Cómo presentar archivos afectados, pruebas, limitaciones y siguientes pasos.

## Resultado esperado

Al finalizar, el participante podrá conducir una tarea de software desde la inspección hasta la entrega, manteniendo trazabilidad, seguridad operativa y revisión humana.

## Criterios ZYRON

- Inspeccionar antes de cambiar.
- Delimitar antes de implementar.
- Reutilizar antes de crear.
- Aplicar el cambio mínimo coherente.
- Verificar antes de declarar terminado.
- Solicitar autorización antes de ampliar el alcance o publicar.
