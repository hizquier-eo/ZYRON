# Centro de Investigacion OpenAI - Plan documental

## Proposito

Este directorio organiza el crecimiento del Centro de Investigacion OpenAI dentro de ZYRON AI LAB. Cada laboratorio mantiene los mismos 14 contenedores para que el contenido pueda crecer sin romper la arquitectura del sitio.

## Contenedores oficiales

1. documentacion
2. imagenes
3. videos
4. tutoriales
5. casos-practicos
6. ejemplos
7. recursos-descargables
8. enlaces-oficiales
9. buenas-practicas
10. comparativas
11. preguntas-frecuentes
12. versionado
13. novedades
14. roadmap

## Prioridad editorial

1. Laboratorio ChatGPT: prompts, asistentes, estudio, escritura, analisis y evaluacion.
2. Laboratorio Codex: desarrollo web, lectura de codigo, depuracion, refactorizacion y publicacion.
3. Laboratorio Sites: construccion de sitios, rutas, componentes, versiones y despliegue.
4. Laboratorio Work: documentos, hojas de calculo, presentaciones, PDF y productividad.
5. Laboratorio Live: voz, tiempo real, reuniones, practica y acompanamiento.
6. Laboratorio Computer Use: navegador, escritorio, aplicaciones y automatizacion supervisada.
7. Laboratorio Conectores: Gmail, Drive, Docs, Sheets, GitHub, Office y APIs.
8. Laboratorio Agentes: roles, herramientas, multiagentes, evaluacion y casos.
9. Laboratorio Automatizacion: procesos, flujos, validacion, errores y escalabilidad.
10. Laboratorio Desarrollo Web: HTML, CSS, JavaScript, UX, pruebas y publicacion.
11. Laboratorio Productividad: organizacion, seguimiento, plantillas, habitos y decisiones.
12. Laboratorio Comparativas IA: criterios, metricas, benchmarks, tablas y evidencia.
13. Laboratorio Casos Reales: diagnostico, solucion, resultado, lecciones y reutilizacion.

## Regla de produccion

Cada laboratorio debe iniciar con una ficha corta en `documentacion`, un tutorial basico, un caso practico, una lista de enlaces oficiales, una pagina de preguntas frecuentes y una entrada de versionado. Despues se agregan imagenes, videos, recursos descargables, comparativas, novedades y roadmap.
