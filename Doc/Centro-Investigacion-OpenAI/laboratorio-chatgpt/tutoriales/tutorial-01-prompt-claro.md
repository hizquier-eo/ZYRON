# Tutorial 01 - Crear un prompt claro

## Objetivo

Aprender a pedirle a ChatGPT una respuesta util, verificable y alineada con una tarea real.

## Estructura recomendada

1. Define el rol: indica desde que perspectiva debe responder.
2. Explica el objetivo: di que resultado necesitas.
3. Aporta contexto: incluye datos, restricciones y audiencia.
4. Pide formato: tabla, lista, resumen, plan, borrador o codigo.
5. Exige verificacion: pide supuestos, riesgos o criterios de calidad.

## Plantilla base

```text
Actua como [rol].
Necesito [resultado].
Contexto: [informacion clave].
Restricciones: [limites, tono, extension, formato].
Entrega la respuesta como [formato].
Antes de finalizar, indica supuestos y puntos que debo verificar.
```

## Ejercicio ZYRON

Crear un prompt para transformar una idea de negocio en un plan de accion de 7 pasos, con riesgos, recursos necesarios y primer entregable.

## Criterio de aprobacion

El resultado debe ser especifico, accionable y facil de revisar por una persona que no participo en la conversacion original.
