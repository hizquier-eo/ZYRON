# Caso practico 01 - Documento institucional

## Situacion

Una organizacion necesita preparar un documento institucional breve para explicar su proposito, servicios y valor diferencial.

## Flujo de trabajo

1. Reunir datos base: nombre, mision, publico, servicios y tono.
2. Pedir a ChatGPT una primera estructura.
3. Revisar que no existan afirmaciones sin soporte.
4. Solicitar una version ejecutiva y una version extendida.
5. Convertir el resultado en documento final con secciones claras.

## Prompt sugerido

```text
Actua como redactor institucional.
Necesito un documento breve para presentar [organizacion].
Usa tono profesional, claro y confiable.
Incluye: proposito, publico objetivo, servicios, valor diferencial y llamado a la accion.
Senala cualquier dato que falte antes de inventarlo.
```

## Entregable

Un borrador institucional listo para revision humana.

## Riesgos a controlar

- Exceso de lenguaje generico.
- Datos inventados.
- Promesas no verificables.
- Tono demasiado comercial para una pieza institucional.
