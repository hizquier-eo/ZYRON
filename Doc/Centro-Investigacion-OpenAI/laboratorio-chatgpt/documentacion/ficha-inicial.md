# Laboratorio ChatGPT - Ficha inicial

## Que es

El Laboratorio ChatGPT es el modulo central para aprender a usar ChatGPT como asistente de investigacion, redaccion, analisis, estudio, ideacion y productividad aplicada.

## Para que sirve

- Convertir preguntas abiertas en instrucciones claras.
- Redactar y revisar documentos.
- Analizar informacion y resumir hallazgos.
- Construir asistentes conversacionales.
- Evaluar respuestas con criterios verificables.

## Que aprenderas

- Como escribir prompts claros.
- Como aportar contexto util.
- Como pedir formatos de salida.
- Como revisar errores, omisiones y supuestos.
- Como convertir una conversacion en un flujo de trabajo repetible.

## Resultado esperado

Al finalizar, el usuario podra usar ChatGPT de forma metodica para producir documentos, ideas, investigaciones, planes y decisiones con mayor claridad y trazabilidad.

## Criterios ZYRON

- Claridad antes que complejidad.
- Evidencia antes que intuicion.
- Iteracion antes que perfeccion inicial.
- Contexto antes que respuestas aisladas.
